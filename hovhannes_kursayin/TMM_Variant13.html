  1. 1. Երկարությունների մասշտաբը

    μl = 0,002 մ/մմ

    Իրական մեխանիզմը թղթի վրա չի տեղավորվի, ուստի այն գծում ենք փոքրացված։ L1 = 0,310 մ հեռավորությունը գծում ենք 155 մմ. μl-ն ցույց է տալիս, թե գծագրի 1 մմ-ը քանի մետր է իրականում։

    μl = իրական երկարությունգծագրային երկարություն = L1L1* = 0,310 մ155 մմ = 0,002 մ/մմ

    Հակառակը՝ ցանկացած իրական երկարություն գծագրային դարձնելու համար այն բաժանում ենք μl-ի. օր.՝ CD* = 0,235 / 0,002 = 117,5 մմ։

  2. 2. Լծակի ճոճման անկյունը

    ψ = 30,0°

    CD լծակը ճոճվում է երկու եզրային դիրքերի միջև։ Այդ դիրքերը որոշվում են սողնակի ամենացածր (E₀′) և ամենաբարձր (E₀) դիրքերով։ ψ-ն այդ երկու դիրքերում DC-ի միջև եղած անկյունն է։

    1. Ստորին դիրք. DC-ն ուղղաձիգից շեղում ենք β = 3° → C₀′(40,1; 140,7)։ Քանի որ CE = CD, DCE եռանկյունը հավասարասրուն է, և E-ն միշտ D-ից ուղիղ ներքև է. DE₀′ = 2·CD*·cos β = 2·117,5·cos 3° = 234,7 մմ → E₀′(34,0; 23,3)։
    2. Վերին դիրք. E₀′-ից բարձրանում ենք HE* = 37,5 մմ → E₀(34,0; 60,8), DE₀ = 197,2 մմ։ E₀-ից R = CE* = 117,5 մմ աղեղը հատում է C-ի հետագիծը C₀(97,9; 159,4) կետում։
    3. Անկյունը. DC₀-ն ուղղաձիգից շեղված է γ անկյունով. cos γ = DE₀/(2·CD*) = 197,2/235,0 = 0,8391 → γ = 32,9°։
    ψ = ∠C₀DC₀′ = γ − β = 32,9° − 3° = 30,0°

    Գծագրում՝ անկյունաչափով չափեք C₀DC₀′ անկյունը։

  3. 3. Կռունկ AB և շարժաթև BC

    AB* = 26,2 մմ, BC* = 123,4 մմ

    Լծակի եզրային դիրքերում կռունկը և շարժաթևը մեկ ուղղի վրա են։ C₀ դիրքում դրանք ծալված են (B₀—A—C₀, A-ն մեջտեղում), C₀′ դիրքում՝ ձգված (A—B₀′—C₀′)։ Այսպիսով A-ից մինչև C₀ և C₀′ երկու հեռավորությունը տալիս են երկու հավասարում՝ երկու անհայտով։

    Կետերը՝ C₀(97,9; 159,4), C₀′(40,1; 140,7), A(189,0; 125,5)։

    AC₀ = √(91,1² + −33,9²) = 97,2 մմ,   AC₀′ = √(148,9² + −15,2²) = 149,6 մմկամ չափեք քանոնով
    BC − AB = 97,2AB + BC = 149,6  ⇒  BC = 149,6 + 97,22 = 123,4 մմ,   AB = 149,6 − 97,22 = 26,2 մմ

    Իրական երկարությունները ստանալու համար գծագրայինը բազմապատկում ենք մասշտաբով.

    lAB = 26,2·0,002 = 0,0524 մ,   lBC = 123,4·0,002 = 0,2468 մ

  4. 4. Կռունկի անկյունային արագությունը

    ω1 = 7,854 ռադ/վ

    n1-ը տրված է պտույտ/րոպե-ով, իսկ հաշվարկի համար պետք է ռադ/վ։ Մեկ պտույտը 2π ռադ է, մեկ րոպեն՝ 60 վ. հետևաբար ω1 = 2πn1/60 = πn1/30։

    ω1 = π·n130 = 3,1416·7530 = 7,854 ռադ/վ

  5. 5. B կետի արագությունը և արագությունների մասշտաբը

    VB = 0,412 մ/վ, pb = 51,4 մմ

    B կետը պտտվում է A-ի շուրջը AB շառավղով, ուստի նրա արագությունը հավասար է անկյունային արագության և շառավղի արտադրյալին։ Այն ուղղահայաց է AB-ին և ուղղված է պտույտի կողմը (↺)։ Կռունկը պտտվում է հավասարաչափ, ուստի VB-ն բոլոր դիրքերում նույնն է։

    VB = ω1·lAB = 7,854·0,0524 = 0,412 մ/վ

    Արագությունների պլանում VB-ն պատկերում ենք pb հատվածով։ Օրինակի տետրում pb-ն վերցված է ≈ 50 մմ. մասշտաբը կլորացնում ենք՝ μV = 0,008 (մ/վ)/մմ։

    pb = VBμV = 0,41150,008 = 51,4 մմ

    Գծագրում՝ pb հատվածը տարեք p բևեռից ⊥ AB։

  6. 6. B կետի արագացումը և արագացումների մասշտաբը

    aB = 3,232 մ/վ², πb = 64,6 մմ

    ω1 = const, ուստի շոշափող արագացում չկա (ε1 = 0)։ Մնում է միայն նորմալ (կենտրոնաձիգ) արագացումը, որը միշտ ուղղված է B-ից դեպի պտտման կենտրոն A։

    aB = ω1²·lAB = 7,854²·0,0524 = 61,69·0,0524 = 3,232 մ/վ²

    Արագացումների պլանի մասշտաբը՝ μa = 0,05 (մ/վ²)/մմ.

    πb = aBμa = 3,2320,05 = 64,6 մմπb ∥ AB, B → A

    Գծագրում՝ πb հատվածը տարեք π բևեռից AB-ին զուգահեռ, B-ից A ուղղությամբ։
