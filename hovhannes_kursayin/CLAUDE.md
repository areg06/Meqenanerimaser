# Kursayin ashxatanq — TMM (Theory of Machines and Mechanisms), Variant 13 (Hovhannes)

University coursework: kinematics and dynamics of a six-link linkage (synthesis, positions, velocity & acceleration
plans, reduced moment, work graphs, reduced moment of inertia, A3/A4 drawings). All user-facing text is in **Armenian**;
keep it Armenian when editing. Make the change, rebuild, and commit the regenerated outputs in the same commit.

Mechanism (differs from Variant 1): crank AB (counter-clockwise), coupler BC, rocker CD, rod CE with **CE = CD**,
slider E on the vertical guide through D (so E = (0, 2·y_C), DCE is isosceles). Task «Առաջադրանք 1», variant 13.
Data: HE=75, L1=310, L2=265, lCD=235, n1=75, G2=200, G5=510, IS2=160, Fmax=82. Thick (acceleration) position = 3,
working stroke = slider moving down (`model.working(i)`: positions 1–4). F_re shape = `FRE_PTS` in model.py.
Scales: μ_l = 0,002, μ_V = 0,008, μ_a = 0,05, μ_F = 200.

## Rebuilding (Python 3, standard library only)

```sh
cd source
python3 model.py && python3 calc.py   # sanity prints (check lines must say OK)
python3 build.py      # -> ../TMM_Variant13.html (also source/variant13.html)
python3 explain.py    # -> ../bacatrutyun.html
python3 tetr.py       # -> ../tetr.html
python3 export.py     # -> ../chertej_A3_{1,2,4}.*, ../chertej_A4_graf.*, ../thumb_*.jpg (PNG/PDF need Chrome at /Applications)
```

- Always edit the Python sources, never the generated files; after changing model/calc/sheet rerun everything.
- Numbers use a comma decimal via `calc.n()`.
- The old `chertej_A3.*` (pre-§4 single sheet) are obsolete.
